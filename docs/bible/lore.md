# Lore has moved

This file used to record what the show had established: its running gags, the state of its set, and
logs of earlier episodes. That record now lives in the reviewers' ledger, which writers, researchers
and builders do not read ([`docs/WORKFLOW.md`](../WORKFLOW.md), "Who may read what"). There is
nothing here to read before writing, and nothing to call back to
([do not repeat the show](03-episode-shape.md#do-not-repeat-the-show)).

This page remains only because chapter 9 (R11) links to it. Where R11 says that an account that opts
out is removed "from lore", that is now done in the ledger, by a reviewer.
